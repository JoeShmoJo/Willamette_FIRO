REPOSITORY STRUCTURE

Project folders: FIRO_COMPONANTS, DELAYED_DRAWDOWN_SCREENING,
ROUTING_RAMP_EVACUATION, RULE_CURVE_WORKSHOP.

Each separated workflow has src (entry-point scripts), config (workflow-specific
configuration), and outputs (ignored generated results/caches).
FIRO_COMPONANTS retains its existing project-local data, src and outputs layout.

SHARED_DATA replaces the former root data folder. Existing content and the
common_data subfolder are preserved pending authoritative-source reconciliation.
External ResSim, SharePoint and temporary contents remain ignored.
modules contains reusable Python utilities shared across projects.
config/PostProcessConfig.xlsx is legacy/unassigned.
out is legacy output; existing files have not been relocated.
docs contains the relocation manifest and original source-folder notes.

Scripts in the three separated workflows resolve inputs/output paths from their
own file locations and can be invoked from any working directory.

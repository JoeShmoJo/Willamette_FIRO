# FIRO outputs

- **[final/](final/README.md)** — final combined curves, one CSV per alternative; use these for downstream analysis. Main files are after reallocation; baseline/ contains before reallocation.
- **[diagnostics/](diagnostics/)** — intermediate calculations, component detail, QA, comparison data, and plots. Open [the review page](diagnostics/review/index.html) to browse.

Run `python FIRO_COMPONENTS/run.py model` to rebuild numerical and final results, or `all` to also rebuild interactive reports.

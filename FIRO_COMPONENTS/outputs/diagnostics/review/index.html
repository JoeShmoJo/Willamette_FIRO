FIRO Targeted Review Package

Use this folder for normal model review. Supporting tables are consolidated in outputs/diagnostics/scenarios. Extra intermediate and QA exports are optional and live in outputs/diagnostics/extra when requested. Daily charts below let you toggle between before and after reallocation; component geometry and status are rebuilt for each case. All daily loading is unrouted storage-space screening.

Review Files

  • Start here: FIRO utilization overview — before/after daily space, relative to physical/control-point capacities.
  • Constraint and component-controller diagnostics — what limits or controls the daily envelope.
  • 01_alternative_summary.csv — alternative-level baseline versus redistribution results.
  • 02_decision_unit_changes.csv — only decision units receiving additional FIRO space.
  • 03_project_changes.csv — only physical projects receiving additional FIRO space.
  • 04_control_point_comparison.csv — baseline and redistributed control-point use side by side.
  • 05_quality_exceptions.csv — warnings, errors, and non-passing QA/QC rows.
  • README_review_package.txt — plain-text explanation of the review package.
  • Plotly Component Review — interactive component geometry pages.
